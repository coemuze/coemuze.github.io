Research, as applied depth

My MSc focused on AI-powered intrusion detection within post-quantum cryptographic environments. That research supports the professional work above: it is about whether the defences organisations already run will still see attacks clearly once the cryptography underneath them changes.

Post-quantum migration, in practice

How hybrid key exchange and post-quantum TLS change traffic characteristics — handshake sizes, timing, and fingerprints — and what that means for monitoring and defence.

Crypto-agile security

Designing systems that can swap cryptographic algorithms without rebuilding the security stack, so migration does not create a window of fragility or blind spots.

AI for intrusion detection

Machine-learning detectors that remain reliable through cryptographic change: fewer false alarms on benign post-quantum traffic, without losing sensitivity to genuine intrusions. This is the QuantumIDS line of inquiry.
